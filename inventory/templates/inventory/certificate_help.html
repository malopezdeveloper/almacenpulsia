2. Windows · Edge / Chrome

  1. Pulse el botón anterior y abra PULSIA-Inventario-Root-CA.crt.
  2. Pulse Instalar certificado.
  3. Seleccione Equipo local (puede solicitar credenciales de administrador).
  4. Seleccione Colocar todos los certificados en el siguiente almacén.
  5. Elija Entidades de certificación raíz de confianza y finalice.
  6. Cierre y vuelva a abrir el navegador. Entre de nuevo usando HTTPS.

3. Firefox

  1. Descargue la CA.
  2. Abra Ajustes → Privacidad y seguridad → Certificados → Ver certificados.
  3. En Autoridades, pulse Importar y seleccione la CA PULSIA.
  4. Autorice la confianza para identificar sitios web y reinicie Firefox.

4. Ubuntu / Debian

Descargue primero el certificado y, desde una terminal, instálelo con permisos administrativos:

sudo cp PULSIA-Inventario-Root-CA.crt /usr/local/share/ca-certificates/
sudo update-ca-certificates

Después reinicie el navegador.

Direcciones admitidas por el servidor

La instalación HTTPS acepta el nombre almacen, el nombre pizarra, 127.0.0.1 y la IP LAN detectada durante la instalación.

Ejemplos: https://almacen, https://pizarra o https://192.168.x.x.

Para usar “almacen” o “pizarra” desde otro ordenador, esos nombres deben resolver a la IP del servidor mediante DNS o el archivo hosts del cliente. El acceso por IP no necesita resolución DNS.
